# KJV Bible Data Repository

This repo contains King James Version biblical texts, Greek/Hebrew source data, and archaeological corroboration notes — a curated archive for personal study and research.

This repository contains **source data only**. It does not contain website publishing scripts, WordPress tooling, or generated website working files.

## Contents

| Directory | Description |
|-----------|-------------|
| `kjv-texts/` | Plain King James Version (KJV) text |
| `kjv-wlc-texts/` | KJV + Westminster Leningrad Codex (WLC) Hebrew parallel; also includes Clementine Vulgate, Textus Receptus, and Septuagint (Swete) data |
| `septuagint-rahlfs-1935/` | Rahlfs 1935 Septuagint: morphology, glosses, Strong numbers, pronunciation, and end-user files |
| `midvash-bible-data/` | Open Bible dataset with many translations in JSON/SQLite form |
| `kjv-archaeological/` | Markdown posts for the KJV Archaeological Corroboration series |

## Notes

- Some files (e.g. SQLite databases) exceed GitHub's 50 MB recommended limit but are kept here for convenience. If the repo grows too large, those can be moved to Git LFS.
- This is a personal research archive; licensing of individual source texts varies by source.
